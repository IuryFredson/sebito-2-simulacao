# Sebito 2.0 - Simulação

Simulação de um sistema de gestão de projetos acadêmicos inspirado no contexto do Sebito, com foco em:

- controle de estados de projetos
- validação de marcos administrativos
- indicadores de saúde de projetos
- integridade de fluxo e regras de negócio

## Stack

### Backend
- Java 21
- Spring Boot
- Spring Web
- Spring Data JPA
- PostgreSQL
- Flyway
- JUnit 5

### Frontend
- React
- Vite
- React Router

## Estrutura

- `backend/`: API e regras de negócio
- `frontend/`: interface web
- `docs/`: documentação do projeto
- `docker/`: arquivos auxiliares de infraestrutura

## Objetivo

Construir um estudo de caso de engenharia de software para modelar problemas de gestão institucional, com foco em qualidade, consistência e evolução sustentável do sistema.
